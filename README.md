# Контрольная работа №3: Адаптивная вёрстка и доступность

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Описание проекта
Проект представляет собой адаптивную версию многостраничного HTML/CSS-сайта интернет-магазина, разработанную на основе проекта КР №1 без использования CSS-фреймворков.

## Структура проекта

```text
kr3-responsive-shop/
├── css/
│   ├── style.css          — основные стили
│   └── responsive.css     — адаптивные стили (Mobile First)
├── images/                — изображения товаров
├── js/
│   └── main.js            — скрипты (модалка, фильтры)
├── lighthouse/
│   └── accessibility-report.png — отчет Lighthouse
├── index.html             — главная
├── catalog.html           — каталог
├── product.html           — товар
├── order.html             — форма заявки
├── about.html             — о компании
├── contacts.html          — контакты
├── README.md
└── .gitignore
```

## Адаптивные решения (ПЗ №12)
- Создан отдельный файл `css/responsive.css`, подключенный на всех страницах после `style.css`.
- Применён подход Mobile First (базовые стили для мобильных, расширение через `min-width`).
- Добавлены медиазапросы для адаптации навигации, сетки карточек, каталога, формы и таблицы характеристик.
- Использованы адаптивные изображения (`srcset`, `sizes`).

## Доступность и Lighthouse (ПЗ №13)
- Проверена семантическая структура страниц (теги header, nav, main, section, article, aside, footer).
- Добавлена ссылка пропуска к основному содержимому (skip-link).
- Добавлен видимый фокус для всех интерактивных элементов (`:focus-visible`).
- Проверены осмысленные `alt`-описания для всех изображений.
- Проверены `label` у всех полей формы.
- Исправлена контрастность цветов и добавлены `aria-label` для кнопок и ссылок.
- Выполнен Lighthouse-аудит (категория Accessibility). Оценка 100.
- Отчёт Lighthouse сохранён в папке `lighthouse/accessibility-report.png`.

## Проверенные ширины экрана
360px, 430px, 768px, 1024px, 1440px.

## Как запустить проект
Откройте `index.html` в браузере.
